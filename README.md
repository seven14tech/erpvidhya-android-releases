# ERPVidhya for Android: release APKs

Signed release builds of the ERPVidhya Android app by seven14tech.

**Download the latest version:** open [Releases](../../releases/latest) and tap the `.apk` file.
Android will ask to allow installs from your browser the first time.

Each release also carries `latest.json`, which the app reads to tell users a new version
is available. Do not upload releases here by hand: use `scripts/release-apk.ps1` in the
app's source repository.
